# 云函数目录

本目录用于存放微信云开发的云函数。

## 使用指南

1. 在微信开发者工具中，右键点击 `cloudfunctions` 目录
2. 选择「同步云函数列表」获取云端函数
3. 或者右键「新建 Node.js 云函数」创建新函数

## 环境配置

请在 `app.js` 中的 `wx.cloud.init()` 配置正确的云开发环境 ID。

获取环境 ID：
1. 打开微信开发者工具
2. 点击「云开发」按钮
3. 在云开发控制台中查看「环境 ID」

## 数据库集合

本项目需要以下集合:
- `teachers` - 老师信息
- `courses` - 课程信息

请在云开发控制台中创建这些集合。
